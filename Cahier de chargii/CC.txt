8. SERVICE API (FRONTEND → SUPABASE)

Exemple fetch produits

import { supabase } from "../config/supabase";

export async function getProducts() {
  const { data, error } = await supabase
    .from("products")
    .select("*")
    .order("createdAt", { ascending: false });

  if (error) throw error;
  return data;
}

1. VISIBILITÉ ADMIN (ZONE PRIVÉE INVISIBLE)

Principe

La zone Admin n’existe pas pour les visiteurs.

Elle doit être :

- Protégée par Auth
- Non indexée (robots.txt)
- URL privée
- Accessible seulement Admin
- Données protégées par RLS

Méthodes utilisées (standard pro)

- Auth Supabase (role admin)
- Middleware protection route
- Vérification token session
- Redirection si non autorisé
- Pages Admin non exposées public

Exemple logique

/admin → vérifie session
si user.role !== admin → redirect home
sinon → accès autorisé
